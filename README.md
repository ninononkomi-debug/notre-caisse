# Notre Caisse

Application Android de la caisse familiale « Ma famille à moi ».

- Chaque membre voit le montant en caisse, qui a cotisé, qui est en retard
- Dépôt déclaré avec capture d'écran obligatoire, validé par les trésorières (Orly, Nelle)
- Cotisations : 2 600 F (travaille), 1 600 F (ne travaille pas), 5 150 F (couple), modifiables
- Mois non payés cumulés, paiement d'avance possible
- Sorties d'argent visibles par tous, annonces de la famille
- Rappels : dernier jour du mois 18 h, le 5 et le 9 à 10 h (seulement si pas encore payé)

Installation : `supabase/schema.sql` dans le SQL Editor du projet Supabase, puis compilation automatique GitHub Actions
(secret `KEYSTORE_BASE64`). APK : Releases › Notre-Caisse.apk.
